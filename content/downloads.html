The latest stable release of Apache Traffic Server is version 9.2.3, which was released on October 9, 2023. Additionally, we continue to support the LTS release train for version 8.1.x, with the current version being 8.1.9, also released on October 9, 2023. We adhere to the Semantic Versioning scheme, aiming to release patch releases frequently and minor releases as needed. Within major versions, all patch and minor releases are compatible.

When downloading from a mirror, it is important to verify the hash and OpenPGP compatible signature. You can find more information on verification here. To validate PGP signatures, you will need the public keys from the release manager, available here. You can also browse through all releases and hash signatures in the Apache Traffic Server Archive.
