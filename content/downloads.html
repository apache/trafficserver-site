The latest stable release of Apache Traffic Server is v10.1.0, released on 2025-8-13. In addition, we continue to support the v9.2.x LTS release train, currently v9.2.10, which was released on 2025-4-02. We follow the Semantic Versioning scheme. The goal is to release patch releases frequently, and minor releases as needed. Within the major versions, all such patch and minor releases are all compatible.

When downloading from a mirror, please be sure to verify the hash and OpenPGP compatible signature. To validate the PGP signatures the public keys from the release manager will be needed. You can also browse through all releases and hash signatures.
